# 巨型透视中文标题封面

为中文开源项目分享长文制作一张 5:2 横版封面，要求原生画布 2500×1000 或其他严格 5:2 尺寸。唯一风格：giant-perspective-chinese-title，巨型透视中文标题。你是封面艺术总监，输出一张完整成品。

## 输入与标题层级
完整标题必须逐字保留：八千字从0到1讲清不一样的读书视频，制作角度对当前版本直接降维打击
将完整标题分为四层，按顺序阅读，字词不删不改：
上部引题：八千字从0到1讲清
最大主标题：不一样的读书视频
次级连接句：制作角度对当前版本
第二视觉重心：直接降维打击
不要重复印一遍完整标题，不另加广告语。中文，面向想用 AI 制作图书故事视频的创作者。

## 内容与封面目标
一本书展开为有因果的连续故事画面；开源工作台组织文稿、配音、AB叙事和字幕。以书页变成立体字建筑的空间隐喻呈现从阅读到视频的制作过程。气氛大胆、有冲击力，第一眼读懂“读书视频”，第二眼看到书页和叙事画面构成的纵深。

## 风格落地与构图
巨型中文标题是画面本体，占据主导空间，以厚重立体字块形成透视舞台和向前展开的路面。字的正面必须清晰，透视主要表现在侧面厚度与投影，不扭坏笔画。一册小比例展开的书在前景边缘，其纸页顺着主标题建筑延伸成少量连续画格，强化尺度，不抢字。阅读路径从左上引题，沿主标题至下方结论。四周留足安全边，不裁字。

## 图文关系与字体
标题像一组实体建筑，受同一束戏剧性侧光照亮。辅助两句使用清晰中粗黑体，依附立体结构边缘形成海报信息层级。主标题用超粗中文无衬线字，第二视觉结论用同一家族。保持完整中文正确，不用随机英文标签，不放小段文章正文。

## 色彩、材料、纹理
深墨黑背景，奶油白主标题正面，朱红和明黄用于实体字侧面与结论重点。强投影、透视纵深、少量速度线和细纸墨颗粒；灯光锐利，色块克制，保持读字对比。

## 禁用与成品标准
不要普通背景贴字、PPT模板、课程售卖海报、收益数字、平台标志、水印、二维码或无关人物。不要错别字、缺字、重复标题或过度透视导致难读。严格 5:2，一张横版成品，只有上述四段标题文字。不要说明、拼图备选或多方案。
