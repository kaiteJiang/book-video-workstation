# 交给 Agent 制作图书故事视频

先让 Agent 读取项目 `AGENTS.md`、[生产手册](runbooks/longform-story-production.md) 和 `skills/producing-book-handdrawn-videos/SKILL.md`。三个生产 Skill 以仓库版本为准；安装到 Agent 技能目录时保留同名目录与 references，并同步更新，避免安装副本沿用旧规则。

## 准备环境

Windows 10/11、Python 3.11、uv、Node.js/npm、FFmpeg 和 FFprobe。按 README 安装依赖并复制 `config.example.yaml` 为本地 `config.yaml`；凭据从环境变量读取，不写进对话、代码或提交。先执行 `uv run bv --help` 查看当前命令，检查配置与工具可用性。环境检查不需要调用付费供应商。

## 提供输入

提供书名和作者、有权使用的书籍文件，或已经定稿的正文。说明现有素材和本次要完成到哪一步。只有目录或书评时，Agent 必须说明资料覆盖范围，不冒充读完全书。作者未知应明确留空，不编造署名。

新写文稿先完整审阅。现成稿且已明确授权直接制作时，可按该授权推进；实质改稿另行呈现，不能把未发生的试听、看图记录成已通过。

## 制作流程

1. 选一个值得讲完整的故事，按事件、冲突、应对、结果推进。常用 6–8 分钟，优先 10 分钟以内，不凑长度，不用去 AI 味 Skill。
2. 编排完整叙事小节。每对 A 是起点，B 是正文发展后的高潮或结果；时间、地点和构图可随剧情变化。先校验计划，再生成媒体。
3. 按故事筛选豆包声音，区分候选目录、账户可用和实际试听。正式语速固定 1.12 倍，用新音频生成 ASR 与字幕时间轴。
4. 先审开头、关键中段、结尾三对代表图，再补全；已有明确最终制作授权时不重复请求同一许可。B 绑定当前 A 的路径和哈希，并在旁白揭晓结果时出场。
5. 渲染 1080×1920、30fps 视频，制作独立 3:4 封面。检查全片、字幕、转场与画面连续性，交付视频、全幅图和可核验清单。

没有固定四张图的长篇默认配置，也不靠延长静帧冒充剧情发展。完整技术检查与用户最终观看是不同状态。

## 恢复与验证

已有制作优先检查 Episode 下的 `current_production.json`，再核对其指向目录的 `delivery.json` 和真实文件哈希。不要直接运行会产生副作用的 `bv next` 来查询状态。没有当前制作指针时，按 Episode 与候选批准合同恢复。

开发检查使用 `uv run pytest -q`，渲染器在 `vendor/story_to_handdrawn_video` 内运行 `npm run check`。本地测试不代表云端额度、音色试听或成片审美已验收。手绘后半段仍需 Agent 编排，不承诺单命令全自动成片。作品、回执、原稿和本地状态留在被忽略的 `workspace/`，不自动上传。
